## Определение

Линейная функция задаётся формулой:

$$
y=kx+b
$$

Её график — прямая.

## Пример

Для $y=2x+1$ при $x=0$ получаем $y=1$, при $x=1$ — $y=3$. Двух этих точек достаточно для построения прямой.

## Обозначения

$k$ — угловой коэффициент; $b$ — ордината точки пересечения с осью $y$.

## Свойства

- При $k>0$ функция возрастает.
- При $k<0$ убывает.
- При $k=0$ постоянна.

Область определения — $\mathbb R$. При $k\ne0$ нуль функции равен $-b/k$.

## Применение

Линейная функция описывает постоянную скорость изменения: например, стоимость поездки с фиксированной подачей и оплатой за километр.
