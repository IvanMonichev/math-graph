# MathGraph

Разделы слева, граф математических терминов в центре. При наведении появляется определение, по клику узел выделяется. Отдельная кнопка в узле открывает материал. Поиск на графе центрирует термин, а на странице материала открывает найденную тему. Слева — дерево, раскрывающееся по нажатию на название раздела, над материалом — хлебные крошки. Режимов «Все темы» и «Путь изучения» нет.

42 термина: арифметика, алгебра, геометрия и функции. Тригонометрия и анализ пока недоступны.

## Запуск

Node.js 24 (минимум 22.12).

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run format       # Prettier
npm run check        # форматирование, kebab-case, unit-тесты, TypeScript, сборка
npx playwright install chromium
npm run test:e2e     # Chromium: desktop и мобильный экран
```

Для уже установленного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` — абсолютный путь к исполняемому файлу. В CI Playwright устанавливает браузер самостоятельно.

## Структура

```text
src/
  app/                      # конфигурация Ant Design, стили, маршрутизация
  pages/                   # граф и страница материала
  widgets/
    layout/                 # рабочая область
    sidebar/                # разделы
    math-graph/             # React Flow, узлы с определениями, управление масштабом
  features/topic-search/    # поиск и переход к узлу
  features/term-highlighting/ # выделение терминов и определения в тексте
  entities/math-topic/model/# типы, операции над графом, адаптер Markdown
data/math-graph.ts          # термины, разделы, связи
content/                   # Markdown-материалы; «Числа» — пример оформления
scripts/                   # выпуск версии и проверка имён
tests/                     # unit и браузерные проверки
.github/workflows/ci.yml    # CI и выпуск GitHub Release по тегу
```

Файлы и каталоги имеют имена в `kebab-case`, компоненты — в `PascalCase`. Имена служебных файлов вроде `README.md` соответствуют общепринятым соглашениям. Проверка имён включена в CI.

React Flow отображает граф, Dagre вычисляет иерархическое расположение по зависимостям. Ant Design предоставляет дерево, поиск, хлебные крошки, кнопки и всплывающие определения. Раздел хранится в query-параметре `category`; материалы доступны по `/topics/:id` и загружаются отдельными Markdown-модулями. Формулы отображаются через KaTeX.

## Добавление термина

Добавьте запись в `topics` файла `data/math-graph.ts`:

```ts
{
  id: 'new-topic',
  title: 'Новая тема',
  category: 'algebra',
  description: 'Определение, которое появится при наведении.',
  formula: 'x^2',
  minutes: 5,
  prerequisites: ['polynomial'],
}
```

Добавьте `content/algebra/new-topic.md` с заголовком `## Определение`. Определение для всплывающей подсказки берётся из `description`, основной материал — из Markdown.

Выделение терминов в Markdown:

```md
**Рациональные числа** можно записать в виде [[fractions|дроби]].
Далее изучите [[operations]].
```

`**текст**` выделяет ключевое понятие полужирным. `[[id|текст]]` создаёт выделенную ссылку с определением при наведении и переходом к теме по клику. У `[[id]]` подпись берётся из названия темы. Разметка не обрабатывается в коде, формулах и существующих ссылках. Неизвестный `id` сохраняется как текст.

Связи `prerequisite` создаются автоматически из `prerequisites`. Дополнительную связь добавьте в `edges`:

```ts
{ source: 'new-topic', target: 'factorization', type: 'related' }
```

Доступные типы: `prerequisite`, `related`, `uses`, `contains`. Основные зависимости показаны сплошными линиями, остальные — пунктиром. Циклы в зависимостях, отсутствующие темы и материалы проверяются тестами.

## Выпуск версии и push

Сначала создайте Git-репозиторий, настройте `origin`, опубликуйте ветку и установите браузер для тестов. Рабочее дерево должно быть чистым, локальная ветка — совпадать с веткой в `origin`.

```sh
npm run release -- patch --dry-run
npm run release -- patch
npm run release -- minor
npm run release -- major
npm run release -- 1.2.0
```

Скрипт проверяет Git, версии и отсутствие тега, запускает `check` и браузерные тесты, обновляет `package.json` и `package-lock.json`, создаёт коммит и аннотированный тег `vX.Y.Z`, отправляет ветку и тег одной командой `git push --atomic`. Force push не используется. При ошибке push локальный коммит и тег сохраняются; скрипт выводит команду повторной отправки. `--dry-run` выполняет предварительные проверки, не меняет файлы и не делает push.

GitHub Actions проверяет изменения в ветках и pull request. Для тегов `v*` после успешных проверок создаёт GitHub Release с архивом `mathgraph.tar.gz`. Развёртывание сайта не настроено. Основа workflow: [документация GitHub Actions для Node.js](https://docs.github.com/en/actions/tutorials/build-and-test-code/nodejs) и [GitHub CLI release create](https://cli.github.com/manual/gh_release_create).

Для размещения `dist/` на сервере нужен fallback на `index.html`. Дальше можно расширять набор терминов и подключить backend через адаптер данных, сохранив текущий интерфейс.

Текст набран локальными шрифтами YS Text и YS Display, как в типографике Яндекса. Основной материал — 17 px с межстрочным интервалом 1.75; на мобильном — 16 px. Источники шрифтов перечислены в public/fonts/font-source.md. Геометрические фигуры отображаются SVG-чертежами в узлах и материалах; поле figure в данных выбирает тип фигуры.
